# Rules for AI agents working on this project

1. Only edit files inside the folder you are assigned (stated by the user).
2. Never edit `router/`, `layout/`, `config.js`, `theme.css`, or `package.json`.
3. Use only CSS variables from `theme.css`; use `<style scoped>`.
4. Frontend only; call the LLM through `shared/llm.js`. No backend.
5. Do not install new packages.
6. Use mock data in a `data/` file inside your feature folder. No real student data.
